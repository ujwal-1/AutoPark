## 1.7 Organisation of the report

The remainder of this report follows the conventional structure of an engineering
dissertation. Chapter 2 reviews the three bodies of work that AutoPark builds on —
occupancy sensing, number plate recognition and gate actuation — and states the gap.
Chapter 3 converts the problem into functional and non-functional requirements and
examines feasibility. Chapter 4 presents the design: the layered architecture, the
data-flow and state models, the database and API contracts, the recognition pipeline and
the hardware design. Chapter 5 describes the implementation of each layer and the
problems encountered while integrating them. Chapter 6 reports the verification results,
including the automated suite, the interface checks and the defect log, and sets out the
measurement protocol for recognition accuracy. Chapter 7 concludes, states the
limitations honestly, and sets out the roadmap. The API reference, the bill of materials
and the reference list are provided as appendices.
