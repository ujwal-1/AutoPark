A.1 Selected code excerpts

The three excerpts below are taken verbatim from the repository. They are chosen because they contain the decisions that the report argues about: canonicalisation, allocation, and the tariff. The line breaks have been adjusted to fit the page; nothing else has been changed.

A.1.1 OCR-aware canonicalisation (backend/app/slot_allocator.py). The map encodes the visual confusions that a low-resolution plate image produces. It is applied to both the reading and the registered plate before any comparison, so the two strings are compared in the same alphabet.

def canonicalize_plate(plate: str) -> str:
    if not plate:
        return ""
    clean = re.sub(r'[^A-Z0-9]', '', plate.upper().strip())
    trans = str.maketrans({
        'I': '1', 'L': '1', 'J': '1',
        'O': '0', 'Q': '0', 'D': '0',
        'Z': '2',
        'S': '5',
        'B': '8',
        'G': '6'
    })
    return clean.translate(trans)

A.1.2 The four decision gates (backend/app/slot_allocator.py, abridged). The confidence floor, the duplicate checks, the ambiguity refusal and the booked-bay preference appear in this order in the code, and the order matters: a duplicate is rejected before matching, so a stationary car cannot consume a second bay while the matcher is still deciding.

# Rule 1: low confidence is ignored, not guessed
if confidence < settings.YOLO_CONFIDENCE_THRESHOLD:
    return {"status": "ignored", ...}

# Rule 3: the plate already has an active session
if active_session:
    return {"status": "already_allocated", "slot": slot_name, ...}

# Rule 4: per-plate cooldown suppresses repeated frames
if not bypass_cooldown:
    in_cooldown, cooldown_slot = is_plate_in_recent_cooldown(
        clean_plate, now, settings.DETECTION_COOLDOWN_SECONDS)
    if in_cooldown:
        return {"status": "already_allocated", "slot": cooldown_slot, ...}

# Rule 5: unique match against pending pre-registrations
match_result = match_entry_pre_registration(eval_candidates, db)
if match_result["status"] == "ambiguous":
    return {"status": "ambiguous", ...}          # refuse, alert the operator

# The booked bay wins if it is still free
if pending_booking and pending_booking.slot_id:
    preferred_slot = db.query(ParkingSlot).filter(
        ParkingSlot.id == pending_booking.slot_id).first()
    if preferred_slot and preferred_slot.status in ["AVAILABLE", "ALLOCATED"]:
        assigned_slot = preferred_slot

A.1.3 Tariff and release (backend/app/slot_allocator.py). Duration is floored to whole minutes with a minimum of one, and the tariff is a single expression, which is why the boundary behaviour can be checked by inspection and by test.

duration_seconds = max(0, int((now - to_utc(active_session.entry_time)).total_seconds()))

The cost that the project actually demonstrates is not its own: it is the marginal sensing cost of a facility. A conventional design needs one sensing device, one mounting point and one power or data drop per bay; this design needs two cameras for the whole lot. At n = 6 the difference is four devices, and it grows by one device per bay thereafter. The report states that structural comparison rather than a purchase total, because the structural comparison is the claim the project is making.
